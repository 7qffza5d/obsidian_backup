## Decisions
|Layer|Choice|Why|

Content storage|Markdown files on disk, no database|No advanced features needed (drafts/tags/search); git-friendly|
Frontmatter|Simple `key: value` lines at top of `.md` file|Trivial to hand-parse, no library needed|
Markdown → HTML|Existing library (`md4c` or `cmark`)|Solved problem with many edge cases; low learning value to hand-roll|
HTTP layer|Hand-rolled from raw sockets|This is where you actually learn — GET-only, no keep-alive initially|
Templating|Simple `{{placeholder}}` string substitution|No need for a full template engine at this scale|
Concurrency|Single-threaded blocking loop|Simple, sufficient for a personal blog; upgrade later if desired|
TLS/HTTPS|Offloaded to a reverse proxy (nginx/Caddy) at deploy time|Not worth building yourself; low learning value, high risk|
