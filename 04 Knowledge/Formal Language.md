# Formal Language

A formal language is a set of strings whose symbols are taken from an alphabet.

This entry is a tag. It is primarily for navigation between various topics of formal language. For greater information than written below, see the [[#Related Concepts]] below.

In the context of formal languages, an alphabet is any set; its members are called letters. While alphabets can be any set, it makes more sense to use an alphabet in the usual sense of the word. See also [[Alphabet (writing)]]. 

A word over an alphabet is a finite sequence (a string) of letters. The set of all words over the alphabet $\Sigma$ is denoted as $\Sigma^*$ using the Kleene star. The length of a word is the number of letters it is composed of. For any alphabet, there is only one word with length 0, which is the empty word or empty string, denoted as $\varepsilon$. 

A language $L$ over an alphabet $\Sigma$ is a subset of $\Sigma^*$. We then call $\Sigma$ the alphabet of $L$. While that is all the definition of a formal language, we are usually more concerned with languages governed by some rules. These rules are called (formal) grammars.

While writing about formal language and its parent fields, computer science and mathematics, we usually drop the formal adjective as redundant, and refer to the other kind of languages as *natural* languages.
